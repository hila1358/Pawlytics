# Paylytics helps you keep track of your pet even when you’re not home.
# It monitors things like food levels and activity, and lets you know if something’s off.
# The system sends data through MQTT to a manager that processes it and triggers alerts when needed. Through a simple GUI app, you can see your pet’s status and even feed them remotely.
# It’s a simple, smart way to make sure your pet is doing okay—without being there all the time.
